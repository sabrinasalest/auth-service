# auth-service

Serviço de login e cadastro, autenticação e recuperação de contas, feito em
Java 21 e Spring Boot. Projeto de estudo com foco em segurança e arquitetura. 

> 🚧 Em construção

## Features (Backlog)
- Cadastro de conta com verificação de e-mail e telefone
- Login com JWT (access token + refresh token rotativo)
- Recuperação de senha
- Auditoria de eventos de segurança

## Stacks
Java 21 · Spring Boot · Spring Security · JPA · Flyway · PostgreSQL · H2 · Maven
