# Requisitos

_Em construção._

## Requisitos funcionais
- RF01: O usuário pode criar uma conta com e-mail e senha e telefone(opcional).
- RF02: O usuário confirma o e-mail por um link com token.
- RF03: O usuário pode fazer login com as credenciais e receber access token e refresh token.
- RF04: O usuário pode recuperar a senha por e-mail.

## Requisitos não funcionais
- RNF01: Senhas armazenadas apenas como hash.
- RNF02: Tokens de recuperação expiram e são de uso único.
- RNF03: Eventos de segurança são auditados.
